Genesis Durable · Current prototype · November 2026

One fleet. A shared companion.

Assistants across Ian’s computers can talk to the same Jupiter. A shared gateway connects the conversations—and gives the agents access to AI models.

A shared contact, not a fresh chat

A2A means agent-to-agent communication. A working assistant sends a message through LiteLLM; Jupiter answers through that same route. His identity and conversation survive restarts.

Useful tools, deliberate limits

Jupiter can read, write, edit and run commands inside his container. He does not yet have outbound fleet-messaging tools or fleet SSH credentials. Saved conversation does not guarantee perfect recall.
